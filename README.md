# 股票系統｜手機決策台

輸入台股代碼 → 自動抓歷史日K → 套用「小朱老師 AI 工作系統｜股票系統」規則 →
輸出 **可進場／等待／不可進場**、歷史回測勝率、交易計畫。

## 檔案
- `app.py`：手機畫面
- `engine.py`：計算引擎（指標、18 型態、結構、生命週期、衰退警報、風控、回測）
- `requirements.txt`：套件清單

## 規則摘要
- 短線 5～15 交易日，淨利 3%（可改 2%）全出，停損以結構失效為準
- 否決：近 2 日跌停、跌破 20 日低點、高檔衰退警報（≥3 項）、風險報酬比 < 1、上方壓力低於 2% 停利價
- 回測：收盤判斷 → 隔日開盤進場 → 先停損後停利 → 跳空以開盤價計 → 期滿收盤出場；扣手續費與證交稅
- 勝率 = 先到停利的比例；樣本 < 10 不顯示，< 30 標示「僅供參考」

## 已知限制（V1.0）
- 量化門檻 V0.1 為測試中，需以回測與實際交易修正
- #13 雙盤底、#14 雙弧底、#16 突破ABC 尚未自動化
- 未納入產業族群、法人籌碼、財報事件、週K
- 回測只用單一股票自身歷史，樣本通常不足 30 筆
